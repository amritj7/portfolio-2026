AI research assistant on MCPPersonal project · 2026

An agentic chatbot that uses MCP tools to search and summarise arXiv papers, running on a local LLM.
  • Built an MCP server in FastMCP with tools for searching arXiv and looking up saved papers, storing each paper's metadata as JSON by topic.
  • Wrote an MCP client chatbot that discovers the server's tools over stdio and runs an agentic loop: the model asks for a tool, the client calls it through MCP, and the result goes back to the model until it answers.
  • Runs on a small local model served by Ollama through its Anthropic-compatible API, and switches to Claude with one environment variable.
