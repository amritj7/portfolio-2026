# Amritansh Dixit — Portfolio

Personal portfolio of Amritansh Dixit, Software Development Engineer III at Citi (Model Risk Management), focused on forward deployed, full-stack and agentic AI engineering.

## What's here

A single, self-contained `index.html`, with no build step:

- **Delivery pipeline hero:** an animated SVG pipeline. On scroll it pins and walks the Assurance Review module through six delivery stages.
- **AI and agentic engineering:** hands-on use of Cognition's Devin coding agent, the Devin Coach offer, and Model Context Protocol (MCP) work.
- **Work index:** filterable, expandable entries for the modules and projects.
- **Career ladder:** SDE1 to SDE3, animated on scroll.

## Tech

- HTML, CSS and vanilla JavaScript
- [GSAP](https://gsap.com) 3.15 with ScrollTrigger, SplitText, DrawSVG and Flip
- [Lenis](https://github.com/darkroomengineering/lenis) for smooth scrolling
- CSS scroll-driven animations for the reading-progress bar
- Respects `prefers-reduced-motion` and works without JavaScript animation libraries

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

Hosted on GitHub Pages from the `main` branch (root).
